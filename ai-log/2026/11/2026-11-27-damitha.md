## Fix: black chart bars (CSP)
- Cause: engine CSP `style-src 'self'` blocks runtime `<style>` tags. shadcn ChartStyle's `--color-*` vars were never defined, so bars were black.
- Fix: charts.tsx and DefectsView.tsx pass `var(--chart-N)` directly. index.css now hides the Radix ScrollArea native scrollbar and imports sonner/dist/styles.css.
- Check: `npm run build` in web/. Not verified in the running app.
